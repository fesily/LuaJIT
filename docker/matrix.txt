# LuaJIT cross-build matrix: one target per line, fields separated by '|'.
#
#   name|cross-prefix|target-cflags|ELF class|endianness|ELF machine|sysroot|jit.arch
#
#   target-cflags  '-' : no extra flags (ABI/ISA comes from the cross compiler)
#   sysroot        '-' : not runnable here, otherwise the QEMU_LD_PREFIX used to
#                        run the freshly built binary under qemu-user
#   jit.arch       expected jit.arch of that run (LJ_ARCH_NAME)
#
# Supported LuaJIT backends in this tree: x86/x64, arm (softfp/hardfp), arm64,
# ppc32 BE, mips/mipsel, mips64/mips64el and the MIPSR6 variants.  There is no
# PPC64 backend (lj_arch.h: `#error "No support for PPC64"`), and s390x/riscv64
# have no backend at all, so they are intentionally absent.
#
# A target whose cross toolchain is not packaged for the host architecture is
# reported as SKIP-NOTOOLCHAIN (e.g. powerpc-linux-gnu is only built for
# amd64 hosts).  A 32-bit target additionally needs a 32-bit buildvm host tool
# (src/host/buildvm.c checks the pointer size); without -m32 support it is
# reported as SKIP-HOSTBITS - use the per-architecture containers for those.
# A target whose emulator is not registered is reported as SKIP-RUN: the build
# and its ELF header are still verified.
